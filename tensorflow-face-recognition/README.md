# TensorFlow Face Recognition — Class Starter

This teaching-oriented starter contains the classes and method signatures planned for a face-recognition project.

## Install

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate
# Linux/macOS: source .venv/bin/activate
pip install -r requirements.txt
```

## First checkpoint

Place an image named `people.jpg` in the project directory, then run:

```bash
python checkpoint.py
```

The checkpoint reads, displays, and saves an image. Face detection and TensorFlow embedding methods are intentionally marked as the next implementation lessons.
