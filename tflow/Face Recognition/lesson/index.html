Lesson 8

Face Recognition

Face recognition identifies an enrolled person by comparing a new descriptor with stored labelled descriptors.

By the end of this lesson, you should be able to explain the complete pipeline—not merely run the code.

Why this lesson matters

Enrolment does not train a large model from scratch. It records one or more descriptors under a name. During recognition, the program generates a new descriptor, finds the nearest enrolled descriptor, and accepts it only if the distance is below a chosen threshold.

The pipeline

  1. Enter a name
  2. Capture several enrolment samples
  3. Store labelled descriptors
  4. Capture a query face
  5. Find the smallest distance
  6. Return the label or Unknown

Important terms

EnrolmentCreating reference samples for an authorized person.
Query faceThe new face currently being tested.
Euclidean distanceStraight-line distance between two descriptor vectors.
ThresholdMaximum distance accepted as a match.
False acceptanceA different person is incorrectly accepted.
False rejectionThe correct person is incorrectly returned as Unknown.

Key code

const matcher = new faceapi.FaceMatcher(labelledDescriptors, 0.55);
const bestMatch = matcher.findBestMatch(queryDescriptor);
console.log(bestMatch.label, bestMatch.distance);

Read the chain from left to right: each stage adds information required by the next stage. A failure early in the chain affects every later result.

Checkpoints
  1. What is the difference between detection and recognition?
  2. What happens when the threshold is too large?
  3. Why must Unknown remain a valid result?

Run the action

  1. Open the action and select Load Models.
  2. Wait for the “Models ready” message.
  3. Provide the requested image or camera permission.
  4. Observe both the output and the status message.

Open action in a new tab

Troubleshooting

  • Everyone is Unknown: add more enrolment samples or improve lighting.
  • Wrong person is selected: use a stricter threshold and better samples.
  • Old samples remain: use the browser storage controls to clear enrolments.

Practice and assessment

  1. Enrol two people using three samples each.
  2. Display the numeric distance beside the result.
  3. Compare thresholds 0.45, 0.55 and 0.65.
Responsible use: obtain informed consent, minimize retention, secure biometric data, allow deletion and correction, provide a non-biometric alternative, and do not use experimental output as proof about identity, attendance, feelings, intent, health or honesty.
