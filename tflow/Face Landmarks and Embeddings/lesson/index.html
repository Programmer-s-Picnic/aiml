Face Landmarks and Embeddings

Convert a detected face into landmarks and a 128-value embedding.

Learning objectives

  • Understand 68 facial landmarks.
  • Generate a descriptor.
  • Separate identity data from a name.

Core idea

Convert a detected face into landmarks and a 128-value embedding.

A face descriptor is a numeric representation. Recognition compares descriptor distance; attendance adds rules and state; expression recognition returns uncertain category scores.

Checkpoint: Explain what the model produces, what threshold or rule is applied, and what could cause an incorrect result.

Workflow

  1. Load only the required models.
  2. Collect input with clear consent.
  3. Run inference in the browser.
  4. Apply the lesson rule and display the result.
  5. Allow correction, deletion and a manual alternative.
