Lesson 7

Face Landmarks and Embeddings

A face detector tells us where a face is. Recognition needs a stable numerical description of that face.

By the end of this lesson, you should be able to explain the complete pipeline—not merely run the code.

Why this lesson matters

Raw pixels change whenever lighting, camera distance, pose or background changes. Landmarks locate important facial points so the face can be aligned. A recognition network then converts the aligned face into a 128-value embedding, also called a face descriptor.

The pipeline

  1. Detect one face
  2. Locate 68 landmarks
  3. Align the face
  4. Generate a 128-value descriptor
  5. Compare descriptors later

Important terms

LandmarkA point describing a visible facial location such as an eye corner or nose point.
AlignmentRotating and scaling a detected face into a more consistent pose.
EmbeddingA compact numeric representation learned by a neural network.
Descriptor distanceA measure of how far apart two embeddings are. Smaller usually means more similar.

Key code

const result = await faceapi.detectSingleFace(image, options)
  .withFaceLandmarks()
  .withFaceDescriptor();

console.log(result.descriptor.length); // 128

Read the chain from left to right: each stage adds information required by the next stage. A failure early in the chain affects every later result.

Troubleshooting

  • No face found: use a clear, front-facing and well-lit image.
  • Landmarks appear displaced: avoid stretched images and extreme head angles.
  • Descriptor changes: variation is normal; compare distance rather than exact equality.

Practice and assessment

  1. Test three images of one person and note how their descriptors differ.
  2. Draw only the eye and nose landmarks.
  3. Calculate Euclidean distance between two descriptors.
Responsible use: obtain informed consent, minimize retention, secure biometric data, allow deletion and correction, provide a non-biometric alternative, and do not use experimental output as proof about identity, attendance, feelings, intent, health or honesty.
