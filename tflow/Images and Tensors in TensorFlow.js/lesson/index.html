Lesson 2: Images and Tensors in TensorFlow.js

In Lesson 1, we learned that a tensor is a container of numbers. In this lesson, we will see how TensorFlow.js converts an image into a tensor.

1. An image is made of pixels

A digital image is made of many small coloured squares called pixels. Pixel means picture element.

An image that is 640 pixels wide and 480 pixels high contains: 

640 × 480 = 307,200 pixels

2. RGB colour values

A colour pixel is commonly represented by three numbers:

  • R — Red
  • G — Green
  • B — Blue

Each number is normally between 0 and 255.

Colour RGB value
Red[255, 0, 0]
Green[0, 255, 0]
Blue[0, 0, 255]
White[255, 255, 255]
Black[0, 0, 0]
Important: A computer does not see a face, eye or smile in an image. It initially sees numbers representing pixels.

3. Image tensor shape

TensorFlow.js normally represents a colour image with this shape: 

[height, width, 3]

The final 3 represents the Red, Green and Blue channels.

For example, a 640 × 480 colour image has the tensor shape:

[480, 640, 3]
Height comes before width in the tensor shape.

4. Converting an image into a tensor

TensorFlow.js provides tf.browser.fromPixels() to read pixels from an HTML image, video or canvas. 

const imageTensor = tf.browser.fromPixels(image);

The following example uses a very small 3 × 3 image so that the pixels are easy to understand.

Select the button to inspect the image tensor.

5. The main JavaScript

const canvas = document.getElementById("pixelImage");

const imageTensor = tf.browser.fromPixels(canvas);

console.log(imageTensor.shape);
console.log(imageTensor.rank);
console.log(imageTensor.dtype);

imageTensor.dispose();

6. Understanding the result

The example produces:

Shape: [3, 3, 3]
Rank: 3
Data type: int32
  • The first 3 is the image height.
  • The second 3 is the image width.
  • The third 3 represents RGB colour channels.
  • Rank 3 means that the tensor has three dimensions.
