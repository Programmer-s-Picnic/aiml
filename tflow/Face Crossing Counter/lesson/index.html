Lesson 6

Face Crossing Counter

Turn face detections into useful events: count people moving from left to right and from right to left across a virtual line.

What you will build: a browser application that opens the webcam, detects faces, gives each visible face a temporary tracking ID, draws a centre line, and updates two directional counters.

Learning objectives

  • Understand why detection alone cannot count crossings.
  • Calculate the centre point of a face box.
  • Match a face in one video frame with a face in the next.
  • Identify a genuine left-to-right or right-to-left crossing.
  • Avoid repeated counts near the line.

1. Detection is not tracking

Lesson 5 detected faces independently in every frame. If the model reports one face in 100 frames, that does not mean 100 people appeared. It may be the same person seen 100 times.

A counter therefore needs a small tracking system. A track is our program's short-lived record of one visible face. It stores an ID, the latest centre position, the last stable side of the line, and the number of frames for which the face has been missing.

2. Find the centre of each face

The detector returns a bounding box. Its centre is a convenient single point to track:

const centreX = face.box.xMin + face.box.width / 2;
const centreY = face.box.yMin + face.box.height / 2;

If centreX is smaller than the line's x-coordinate, the face is on the left. If it is larger, the face is on the right.

3. Match detections between frames

For every new face centre, the example finds the nearest unmatched track. If the distance is reasonably small, it treats them as the same face:

function distance(a, b) {
  return Math.hypot(a.x - b.x, a.y - b.y);
}

If no existing track is close enough, the program creates a new track with a new ID. Tracks that remain missing for several frames are removed.

Important: this is simple centroid tracking for learning. It is not face recognition. IDs may change if faces overlap, move very quickly, or leave and re-enter the camera view.

4. Count a crossing—not a position

A person is counted only when their stable side changes:

Previous stable sideNew stable sideAction
LeftRightIncrease Left → Right
RightLeftIncrease Right → Left
LeftLeftDo nothing
RightRightDo nothing

5. Add a dead zone

Detection boxes naturally shake by a few pixels. Without protection, a stationary face near the line could appear to cross back and forth. The example creates a narrow middle area:

function sideOfLine(x, lineX) {
  if (x < lineX - DEAD_ZONE) return "left";
  if (x > lineX + DEAD_ZONE) return "right";
  return "middle";
}

A new direction is confirmed only after the face has moved completely beyond this middle area.

8. Practice tasks

  1. Move the line to 40% of the frame width.
  2. Add a third display showing the total crossings.
  3. Play a short sound whenever a crossing is recorded.
  4. Change the app to use a horizontal line and count top-to-bottom versus bottom-to-top.
  5. Record the time of the most recent crossing.

Limitations and responsible use

  • A face counter estimates crossings; it should not be treated as an exact security or billing system.
  • Ask for permission before using cameras around other people.
  • This example processes frames inside the page and does not intentionally upload them.
  • Performance and accuracy vary with lighting, camera position, face size, movement, and device speed.
