Lesson 10

Emotion Recognition

Expression recognition estimates visible facial patterns; it cannot know a person’s true inner emotion.

By the end of this lesson, you should be able to explain the complete pipeline—not merely run the code.

Why this lesson matters

After detecting and aligning a face, an expression model returns a score for each learned category. The largest score is simply the model’s current best estimate. Scores can change with pose, lighting, culture, disability, masking and ordinary individual differences.

The pipeline

  1. Detect faces
  2. Locate landmarks
  3. Run the expression classifier
  4. Receive category scores
  5. Display scores with uncertainty
  6. Avoid unsupported conclusions

Important terms

Expression scoreModel output for a visible-expression category.
Dominant labelThe category with the largest score, not necessarily a fact.
Confidence thresholdA rule for withholding a label when no score is strong enough.
SmoothingAveraging several frames to reduce rapid label changes.
BiasSystematic performance differences across people or conditions.

Key code

const results = await faceapi.detectAllFaces(video, options)
  .withFaceLandmarks()
  .withFaceExpressions();

console.log(results[0].expressions);

Read the chain from left to right: each stage adds information required by the next stage. A failure early in the chain affects every later result.

Checkpoints
  1. Why are scores estimates rather than facts?
  2. Can a smile prove happiness? No.
  3. Why is this unsuitable for discipline, hiring, diagnosis or lie detection?

Run the action

  1. Open the action and select Load Models.
  2. Wait for the “Models ready” message.
  3. Provide the requested image or camera permission.
  4. Observe both the output and the status message.

Open action in a new tab

Troubleshooting

  • Labels flicker: average several frames or add a threshold.
  • No face detected: improve light and face the camera.
  • Confident but wrong label: confidence is not correctness.

Practice and assessment

  1. Show only the highest score when it exceeds 0.60.
  2. Plot scores over ten frames.
  3. Add a clear “No confident estimate” result.
Responsible use: obtain informed consent, minimize retention, secure biometric data, allow deletion and correction, provide a non-biometric alternative, and do not use experimental output as proof about identity, attendance, feelings, intent, health or honesty.
