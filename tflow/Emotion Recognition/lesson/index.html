Lesson 10

Expression Recognition with TensorFlow.js

Use live facial landmarks to study visible expression patterns in the browser.

By the end of this lesson, you should be able to explain the complete pipeline—not merely run the code.

What are we building?

The browser receives live video from the webcam. TensorFlow.js detects a face and estimates hundreds of facial landmarks. We then measure a few visible geometric features such as mouth opening, mouth-corner position and eyebrow position.

Those measurements are used to demonstrate simple categories such as smile-like, surprise-like, and neutral-like.

Important: visible facial patterns are not reliable evidence of a person's true feelings, intent, honesty, health, personality or mental state.

The pipeline

  1. Load TensorFlow.js.
  2. Load the TensorFlow.js BlazeFace detector.
  3. Load the TensorFlow.js FaceMesh landmark model.
  4. Start the webcam.
  5. Detect each visible face with BlazeFace.
  6. Run FaceMesh only when a face is detected.
  7. Measure landmark geometry.
  8. Create visible-expression estimates.
  9. Draw the result over the camera image.

Load TensorFlow.js and both models

This lesson deliberately separates face detection from landmark estimation. BlazeFace first answers, “Where is the face?”. Only when a face is found do we run FaceMesh to estimate detailed landmarks. Both models run with TensorFlow.js in the browser.

Load the models

await tf.setBackend("webgl");
await tf.ready();

const faceDetector =
  await window.blazeface.load();

const faceMeshModel =
  await window.facemesh.load({
    maxFaces: 5
  });

Start the camera

const stream =
  await navigator.mediaDevices.getUserMedia({
    video: {
      facingMode: "user",
      width: { ideal: 640 },
      height: { ideal: 480 }
    },
    audio: false
  });

video.srcObject = stream;
await video.play();

Stage 1 — Detect the face

const detections =
  await faceDetector.estimateFaces(
    video,
    false
  );

BlazeFace is a lightweight TensorFlow.js face detector. If this stage returns zero faces, there is no reason to run the more expensive landmark model for that frame.

Stage 2 — Estimate landmarks

let meshFaces = [];

if (detections.length > 0) {
  meshFaces =
    await faceMeshModel.estimateFaces(
      video,
      false,
      false
    );
}

FaceMesh returns a detailed facial mesh. The action displays both counts separately: Faces detected and Landmark faces. This makes debugging much easier.

What does a detected face contain?

boxThe rectangular region containing the detected face.
keypointsHundreds of x, y and z coordinates describing facial geometry.
x and yThe position of each landmark in the image.
zAn approximate depth-related coordinate for the landmark.

Useful FaceMesh landmarks

Normalize measurements

Measurements change when the face moves closer to or farther from the camera. To reduce this effect, we divide measurements by the distance between the eyes. 

const eyeDistance =
  distance(points[33], points[263]);

const mouthOpen =
  distance(points[13], points[14])
  / eyeDistance;

This produces a relative measurement instead of a raw pixel measurement.

Build transparent expression estimates

A simple educational rule can combine normalized measurements. 

const smile =
  clamp(
    (cornerLift + 0.015) * 9 +
    (mouthWidth - 0.75) * 0.8
  );

const surprise =
  clamp(
    (mouthOpen - 0.055) * 7 +
    (browDistance - 0.20) * 1.2
  );

These rules are intentionally visible. Students can change a threshold, run the camera again, and immediately see how the behaviour changes.

Save the analysed image

The action includes a Save Image button. It combines the live webcam frame with the TensorFlow.js overlay so the saved PNG contains the face box, landmarks and current visible-expression estimate. 

capture.toBlob(blob => {
  const url = URL.createObjectURL(blob);

  const link = document.createElement("a");
  link.href = url;
  link.download = "tensorflow-expression.png";
  link.click();

  URL.revokeObjectURL(url);
}, "image/png");

The webcam is mirrored on screen, so the save routine mirrors the video before drawing the overlay. This makes the downloaded image match what the user sees in the browser.

Troubleshooting

  • Model loading failed: check the browser console and internet connection.
  • Camera does not start: allow camera permission and use HTTPS or localhost.
  • No face detected: improve lighting, keep the whole face visible and face the camera.
  • Detection is slow: reduce maxFaces to the number of faces actually expected.
  • Labels change rapidly: average measurements across several frames.

From landmarks to a trained classifier

The next step is to train a separate TensorFlow model. The face detector can crop the detected face, resize it, convert it to a tensor and pass it to that classifier. 

const model =
  await tf.loadLayersModel(
    "./model/model.json"
  );

const prediction =
  model.predict(faceTensor);

This separates two machine-learning problems clearly: where is the face? and how should this face image be classified?

Responsible use: obtain informed consent, minimize retention, secure biometric data, provide non-biometric alternatives, and never use experimental facial analysis as proof for discipline, hiring, diagnosis, lie detection or other high-impact decisions.
