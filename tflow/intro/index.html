Lesson 1: Introduction to TensorFlow.js

TensorFlow is an open-source machine-learning library. It helps us create programs that can learn from examples and make predictions.

TensorFlow can be used for:

  • Face detection
  • Face recognition
  • Image classification
  • Speech recognition
  • Text processing
  • Data prediction

TensorFlow.js

TensorFlow.js is the JavaScript version of TensorFlow. It allows machine-learning programs to run directly inside a web browser.

This is useful because a browser can access images, videos and the webcam. We will use these features later for face detection and face recognition.

Adding TensorFlow.js

We can add TensorFlow.js to an HTML page using a CDN.

CDN means Content Delivery Network. It allows us to use a library through an internet link without downloading it. 
<script src="https://cdn.jsdelivr.net/npm/@tensorflow/tfjs@4.22.0/dist/tf.min.js"></script>

After the library loads, TensorFlow.js is available through an object named tf.

Hello World with TensorFlow.js

This example creates two one-dimensional tensors and adds their corresponding values. 

const first = tf.tensor1d([1, 2, 3]);
const second = tf.tensor1d([10, 20, 30]);

const answer = first.add(second);
The result will appear here.

Understanding the result

1 + 10 = 11
2 + 20 = 22
3 + 30 = 33

Answer: [11, 22, 33]

What is a tensor?

A tensor is a container of numbers. It is similar to a JavaScript array, but TensorFlow can perform fast mathematical operations on it.

Images are also represented as tensors. This will become important when we begin face detection.
