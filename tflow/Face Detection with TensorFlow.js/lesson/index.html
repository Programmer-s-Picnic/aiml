Lesson 5: Face Detection with TensorFlow.js

In Lesson 4, we converted webcam frames into tensors. We can now pass those live images to a pretrained model and ask it to locate faces.

1. What is face detection?

Face detection answers the question: Where are the faces? It returns the location of each detected face, usually as a rectangle.

Face detection does not identify a person. Recognition—answering “Whose face is this?”—is a later project.

2. Detection result

A detector can return a box containing:

ValueMeaning
xMinLeft edge of the face
yMinTop edge of the face
widthWidth of the detected face
heightHeight of the detected face

3. Pretrained model

A pretrained model has already learned from a large collection of examples. We load it and perform inference instead of training a new detector in this lesson.

4. Creating the detector

const detector = await faceDetection.createDetector(
  faceDetection.SupportedModels.MediaPipeFaceDetector,
  {
    runtime: "tfjs",
    modelType: "short",
    maxFaces: 10
  }
);
  • runtime: "tfjs" runs the model through TensorFlow.js.
  • modelType: "short" is suitable for faces relatively close to the camera.
  • maxFaces limits the number of returned faces.

5. Detecting faces

const faces = await detector.estimateFaces(video, {
  flipHorizontal: false
});

The result is an array. No detected face gives an empty array. The number of elements is therefore the current face count. 

const faceCount = faces.length;

6. Drawing bounding boxes

A transparent canvas is placed over the video. Each face box is drawn using strokeRect(). 

faces.forEach(face => {
  const box = face.box;

  context.strokeRect(
    box.xMin,
    box.yMin,
    box.width,
    box.height
  );
});
The canvas drawing size must match video.videoWidth and video.videoHeight. Otherwise, the rectangles will not align.

7. Continuous detection loop

Video changes continuously, so detection must repeat. We wait for one prediction to finish before requesting the next frame. 

async function detectFaces() {
  if (!running) return;

  const faces = await detector.estimateFaces(video);
  drawFaces(faces);

  requestAnimationFrame(detectFaces);
}

Waiting with await prevents multiple model predictions from piling up at the same time.

9. Application workflow

  1. Load TensorFlow.js and the pretrained model package.
  2. Create the detector once.
  3. Ask for webcam permission.
  4. Match the canvas size to the video.
  5. Estimate faces in the current frame.
  6. Clear the earlier canvas drawing.
  7. Draw a box around every current face.
  8. Repeat until the user stops the application.

10. Detection limitations

  • Very small or distant faces may be missed.
  • Dark lighting and strong backlighting reduce accuracy.
  • Side-facing or partly covered faces can be harder to detect.
  • Model confidence is not a guarantee of correctness.
  • Performance varies across phones, browsers and computers.

Privacy rules

  • Ask permission before starting the camera.
  • Clearly show when detection is running.
  • Do not save frames without informed consent.
  • Do not treat a detector result as proof of identity.
