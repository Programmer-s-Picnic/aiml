Lesson 4: Converting Webcam Frames into TensorFlow.js Tensors

Lesson 3 displayed live webcam video. TensorFlow cannot directly understand what we see on the screen. It needs the current video frame as a tensor containing numerical pixel values.

1. From live video to numbers

A live camera application follows this sequence:

Camera → Video element → Current frame → Tensor → Machine-learning model

The video element continuously displays new frames. TensorFlow.js can read the pixels visible in the current frame.

2. Adding TensorFlow.js

<script src="https://cdn.jsdelivr.net/npm/@tensorflow/tfjs@4.22.0/dist/tf.min.js"></script>

3. Converting the current frame

const frameTensor = tf.browser.fromPixels(video);

tf.browser.fromPixels() reads the visible pixels and creates a rank-3 tensor.

If the live video is 640 pixels wide and 480 pixels high, the tensor normally has the shape [480, 640, 3]. Height comes first.

4. Understanding the tensor

PropertyTypical resultMeaning
shape[480, 640, 3]Height, width and RGB channels
rank3Three dimensions
dtypeint32Integer pixel values
size921,600Total numerical values

The number of values is calculated as:

480 × 640 × 3 = 921,600

5. Wait until the video is ready

Do not convert the frame before the video has received camera data. A simple check is: 

if (video.readyState < 2) {
  console.log("The video frame is not ready.");
  return;
}

6. Dispose of every frame tensor

Webcam processing creates tensors repeatedly. Tensor memory must be released as soon as a frame has been processed. 

const frameTensor = tf.browser.fromPixels(video);

// Inspect or process the frame here.

frameTensor.dispose();
If a program creates 30 tensors every second and never disposes them, memory usage will grow continuously. This is called a memory leak.

TensorFlow.js can report the number of active tensors:

console.log(tf.memory().numTensors);

8. What happens when the button is selected?

  1. The program checks that a video frame is ready.
  2. fromPixels() copies the frame pixels into a tensor.
  3. The tensor's shape, rank, type and size are displayed.
  4. dispose() releases the tensor.
  5. The active tensor count returns to its earlier value.

9. Preparing images for a model

Models often require a fixed image size and decimal values between 0 and 1. A later lesson will explain this preprocessing in detail. The basic idea is: 

const preparedFrame = tf.tidy(() => {
  const frame = tf.browser.fromPixels(video);
  const resized = tf.image.resizeBilinear(frame, [224, 224]);
  return resized.toFloat().div(255);
});

preparedFrame.dispose();
tf.tidy() automatically disposes intermediate tensors created inside its function, except for the tensor that is returned.
