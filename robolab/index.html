Quick robot command reference

move()

Move forward exactly one square.

turn_left()

Rotate 90° counter-clockwise.

turn_right()

Rotate 90° clockwise.

repeat(3):

Repeat the indented code three times (maximum 30).

if wall_ahead():

Run the indented commands only when a wall is ahead.

scan()

Report whether a wall is in front of the robot.

pick()

Pick up a sample beneath the robot.

drop()

Put down the carried sample.

# comment

Add a note: comments are ignored by the robot.
