〰️ Line tracking

Explore the left and right line detectors and a reference line-tracking controller that steers toward a route.

Humanoid learning model: motors(left,right,ticks) controls simplified left/right gait drives to demonstrate steering and sensing. Walking animation is illustrative; it does not model humanoid balance, joint torques or real walking hardware.

Command reference & what comes next

  • motors(left, right, ticks) — simulated left/right gait-drive percentage; negative means reverse. Example: motors(50,-50,4) rotates clockwise or counterclockwise depending on coordinate direction (in this arena, rightward is 0°).
  • distance_cm() — simulated forward range to the first obstacle or arena boundary. Use inside if distance_cm() < 28:, not as standalone Python.
  • obstacle_ahead() — true when front range is under 35 simulated centimetres. line_left() and line_right() check two virtual downward-facing detectors.
  • scan() — write the distance and line detector readings to the console.
  • repeat 12:, if ...: and else: — use a four-space indentation to group instructions.
  • follow_line(ticks) — a waypoint-assisted reference controller for learning closed-loop motion. It automatically adjusts motor powers. This is an educational helper, not a full physical sensor-only line-following algorithm.
  • pick() and drop() — crouch, grab, carry and release an object; practise in the final delivery mission.
  • brake() — stop the robot and finish execution.

Simulation note: Motor speeds, sensor ranges and robot movement are simplified learning models. They do not represent verified real-world hardware. Level 3 can introduce PID, joint encoders, balance control, hardware calibration, Arduino/ESP32 and safe physical robot control.
